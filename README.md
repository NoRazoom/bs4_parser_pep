# Проект парсинга pep

Для запуска парсера, находясь в директории src, нужно ввести в командую строку терминала: python main.py <режим>.

Программа предоставляет работу с 4 режимами парсинка, которые нужно указать позиционным параметром вместо <режим>: {whats-new,latest-versions,download,pep}.

Парсеры программы:
- whats_new - предоставляет данные об обовлениях с официального сайта Python
- latest_versions - предоставляет данные о последних версиях Python
- download - позволяет скачать архив документации Python
- pep - передает данные о разных статусах pep и сколько pep принадлежит конкретному статусу.

Программу можно запускать в режиме без кэширования: -c, --clear-cache. Данный флаг очищает кэш.
А так же можно выбрать способ вывода информации для тех парсеров, которые выводят информацию:  -o {pretty,file}, --output {pretty,file}

Вы всегда можете воспользоваться командой python main.py -h для того, что бы увидеть весь функционал программы.
